## Direct advisories and patch floors

- [GHSA-f88m-g3jw-g9cj](https://github.com/advisories/GHSA-f88m-g3jw-g9cj): sharp <0.35.0; vulnerable GIF/TIFF/VIPS loaders in libvips. Advisory recommends current prebuilt libvips, with 8.18.3 referenced. This worker has libvips 8.17.3.
- [GHSA-rgj7-g3m4-5g8c](https://github.com/advisories/GHSA-rgj7-g3m4-5g8c): sharp <0.35.4; libheif heap buffer overflow, possible RCE on glibc Linux under documented conditions. Patched prebuilt libheif 1.23.2; installed 1.20.2. PIE can affect exploitability; no claim that this host is immune.
- [GHSA-wq5f-xc86-pv6w](https://github.com/advisories/GHSA-wq5f-xc86-pv6w): sharp <0.35.5; librsvg memory safety/CVE-2026-96889. Patched librsvg 2.63.2; installed 2.61.2. SVG decoding remains unsafe if enabled for untrusted images.
- [GHSA-hp3w-g68c-fv3c](https://github.com/advisories/GHSA-hp3w-g68c-fv3c): sprintf-js <=1.1.3, no patched version. Precision validation is missing before toFixed/toExponential/toPrecision.

All four advisory pages were successfully read over verified HTTPS during this task. The sharp advisories describe loader-blocking workarounds. No such runtime modification was applied without real inference verification; restricting unused image support is not a substitute for a supported patch.

## Decision and remaining exposure

No advisories fixed in this task. The previous Vitest fix remains intact. Package lock and model source/weights/digests are unchanged. Clean installation, native import, TypeScript and deterministic fallback tests do not prove compatibility with a different inference stack.

The text-only runtime and fixed installer log formats narrow currently identified exposure. They do not remove vulnerable code from disk, establish comprehensive non-reachability, or protect a future image feature, dependency behavior change, or alternate caller. Avoid adding server image processing or user-controlled logger formats before remediation. Retain these findings in release review.

Once the original weights are accessible, first establish genuine inference on this locked stack. Test a supported Transformers 4.3.1 upgrade separately before final calibration/freeze: verify every unchanged asset, 384-dimensional finite normalized outputs, the original benchmark, application semantic review and complete tests. Check its resolved sharp version is at least 0.35.5. Do not alter model hashes or silently accept changed evaluation behavior. No model breakage or compatibility is claimed here.
